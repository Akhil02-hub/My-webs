\# Athidhi Grand



A modern, responsive restaurant website designed for \*\*Athidhi Grand\*\*, providing customers with an elegant online experience to explore the restaurant, menu, services, gallery, and contact information.



\## ✨ Features



\* 🏠 Modern restaurant homepage

\* 🍽️ Digital food menu

\* 📱 Fully responsive design

\* 🖼️ Restaurant gallery

\* 📞 Contact and location information

\* 📅 Reservation / booking functionality

\* 🔗 Social media integration

\* ⚡ Fast and lightweight frontend

\* 🎨 Modern UI with smooth animations

\* 👨‍💼 Admin dashboard for managing website content



\## 🛠️ Tech Stack



\* \*\*Frontend:\*\* HTML5, CSS3, JavaScript

\* \*\*Backend:\*\* Python / Flask

\* \*\*Database:\*\* SQLite

\* \*\*Server:\*\* Gunicorn

\* \*\*Deployment:\*\* Render

\## 🌐 Deployment



The application can be deployed using \*\*Render\*\*.



\### Build Command



```bash

pip install -r requirements.txt

```



\### Start Command



```bash

gunicorn app:app

```



\##Live web link :- https://athidhigrandhotel.onrender.com/



\## 🔐 Admin Panel



The website includes an admin panel for managing restaurant content such as:



\* Menu items

\* Restaurant information

\* Gallery images

\* Customer bookings

\* Reviews

\* Other website content



Admin authentication should be configured using environment variables rather than storing credentials directly in the source code.



\## 📱 Responsive Design



Athidhi Grand is designed to work across:



\* 📱 Mobile phones

\* 📲 Tablets

\* 💻 Laptops

\* 🖥️ Desktop computers



\## 🎯 Purpose



The website is built to give Athidhi Grand a professional online presence and make it easier for customers to discover the restaurant, explore its menu, view the restaurant, and contact or book the restaurant.
